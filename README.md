## 🔮 Tentang Sang Peneliti

Mahasiswa Teknik Informatika & Komputer di **Politeknik Negeri Bandung**, menghabiskan sebagian besar waktu (dan simulasi) di antara code editor dan viewport 3D. Anggap saja aku ini "puppet" yang menjalankan eksperimen dari jarak jauh — bedanya, "stasiun luar angkasa"-ku cuma laptop.

- 🧪 Sedang bereksperimen dengan **procedural generation** di Blender
- 🎮 Membangun dunia interaktif & sistem kamera di **Roblox Studio**
- 📱 Merancang aplikasi mobile untuk masalah sehari-hari (logistik kos, misalnya)
- 📚 Sesekali menyelesaikan persamaan diferensial untuk hiburan (penggemar metode Frobenius)
